# The Israeli Tech Resume Checklist (2026 Edition)

Israeli tech hiring is unique. The culture is informal, the ecosystem is startup-heavy, and the hiring process moves fast. Here's what Israeli tech recruiters and hiring managers actually look for.

## The Basics

- [ ] **One page for most candidates** — two pages max for 10+ years of experience
- [ ] **Hebrew and English versions** — have both ready; use the language of the job posting
- [ ] **Photo is optional** — common but not required; avoid if applying internationally from Israel
- [ ] **Military service listed** — relevant for Israeli candidates, include role and unit (no classified details)
- [ ] **ID number: never include** — security risk, no recruiter needs it at this stage

## Contact Info

- [ ] Phone number with country code (e.g., +972-50-xxx-xxxx)
- [ ] LinkedIn URL (make sure it's up to date)
- [ ] GitHub profile (if relevant — it will be checked)
- [ ] Location: city is enough, not full address

## Tech Stack Section

- [ ] List languages you'd be comfortable being interviewed on
- [ ] Group by category: Languages, Frameworks, Cloud, Tools
- [ ] Don't list things you learned in a weekend tutorial
- [ ] For each listed skill, be ready to answer: "tell me about a project where you used X"

## Experience

- [ ] Reverse chronological order (most recent first)
- [ ] Startup names: add a one-line description if they're not well-known ("B2B SaaS for logistics, 80 employees")
- [ ] Quantify impact: users, revenue, latency, scale
- [ ] "R&D" is understood in Israeli tech — more common than "Engineering"
- [ ] Military projects: describe in civilian terms, omit classified details

## Education

- [ ] Israeli degrees are understood without translation
- [ ] Include graduation year
- [ ] GPA is optional — include if above 85 (Israeli grading out of 100)
- [ ] Bootcamp/online courses: list with completion date and issuer

## What Israeli Hiring Managers Actually Look For

Based on recruiter feedback, the top signals that get candidates past the screening stage:

1. **Relevant technical depth** — specifics beat generalities
2. **Evidence of ownership** — led a feature, not just "contributed to"
3. **Scale and context** — "at a 300-person startup" adds information
4. **Genuine English proficiency** — most Israeli tech companies work in English internally
5. **Fast progression** — Israeli culture rewards hustle and rapid growth
